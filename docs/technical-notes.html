Technical Notes

Reviewed version: 1.1.39 (version code 172)

Last updated: November 4, 2026

Platform and architecture

Flex4WiiM is an independent Android controller for compatible WiiM devices. Android 9 or later is required (minSdk 28); the project targets Android 15 (API 35). Package identifier: org.wiimer.controller.

The app combines native Java services with a bundled HTML/CSS/JavaScript interface inside Android WebView. The internal https://app.local address serves bundled app content; it is not a developer-operated internet service. Direct WebView file/content access and cookie acceptance are disabled, and mixed content is disallowed in WebView. Native network features have their own controls; these WebView settings do not mean all app traffic is encrypted.

Configure devices and music-service accounts in WiiM Home first. Keep the Android controller and speakers on the same trusted home network. Music services and artwork may require internet access.

Device control and trust

WiiM HTTPS control requests are restricted to private network addresses and supported operations. Initial read-only registration inspection observes a certificate fingerprint. The user reviews the devices and explicitly approves registration; subsequent control requests check saved fingerprints. A changed trusted certificate needs separate confirmation. Device-reported names are not proof of identity.

Group discovery and optional WiiM Home group import read device identities and membership. Importing saved registrations does not itself activate a physical group. Group activation, playback, presets and alarms can subsequently change actual speaker state.

Audio paths

  • Home Music Share / UPnP/DLNA: browsing and discovery from Android; playback normally transfers from the media server directly to WiiM. Some traffic uses unencrypted HTTP.
  • My Music: Android exposes selected audio through a temporary local HTTP server restricted to the selected WiiM IP and a randomized resource path. The phone must remain reachable.
  • Open Network Stream: a saved URL is used for playback on WiiM. The app may also fetch it for supported analysis or related functions.
  • Artwork and metadata: supplied by devices or source services; external artwork servers may receive requests. Missing metadata is not necessarily an app rendering fault.

Groups, stereo pairs and Scenes

The app stores device/group registrations, app-managed stereo pairs and up to 500 Scenes. A Scene recalls its target/group configuration and supported source reference; it is not an independent snapshot of all volume, input, output and EQ settings. A device preset can itself change output or group configuration.

Presets omitted from a device's preset list can be referenced manually by number in a Scene. This does not create a new preset on the device or prove that the slot is populated. Bulk registration covers registered devices/groups for the supported source types. Related Scenes are removed with the corresponding confirmed group deletion or leader-change operation.

Per-device/group direct-volume values can override common defaults. Editing those values does not itself change playback volume; activating a volume button does.

Home theater switching — beta

Automatic monitoring and manual switching are separate options. Automatic monitoring periodically reads input/group/playback state and applies configured rules. It can continue reconnecting after temporary read failures. Stopping monitoring is not equivalent to restoring speaker settings.

Manual switching offers two independent, default-off options: follower volume correction and follower channel assignments. They apply to explicit group-icon and Scene activation in the app, not headless scheduled alarms. Volume targets use the recorded baseline plus the configured correction, clamped to 0–100, rather than repeatedly adding to the current volume. Channel-only operation does not require a volume baseline.

The app verifies identities and group membership, records the affected settings locally, applies channel changes before volume changes, and reads back results. Scene presets run before the subsequent manual-theater verification/application. Stereo-pair synchronization is coordinated to avoid overwriting settings owned by this operation.

When leaving, restoration is conditional on the original devices/topology and observed values. External setting changes are preserved where detected. If the group topology has changed externally, the operation record can be discarded without restoring. Failed or interrupted operations may leave changes in place; check actual speaker volume and channels if an error is shown.

Analyzer and DSP — beta

Supported source audio is read/decoded on Android for analysis. This can open a second source connection and differ in timing from WiiM playback. No microphone capture, capture of other apps' output, or direct measurement of WiiM's post-EQ/RoomFit output is provided. DSP/headroom displays are theoretical estimates, not guaranteed clipping or safe-volume measurements.

Alarms, timers and background work

Scene alarms, one-tap sleep timers, Android media controls and monitoring depend on device responses, network availability and Android background rules. They are convenience features and cannot guarantee precise timing or restoration after every interruption.

Changes reflected since the earlier documents

The 1.1.39 documentation includes manual home theater options and restoration records, target-specific direct volume, expanded Scene registration/cleanup, offline-aware sorting and the latest player layout preferences. Startup checks prioritize the selected device and display replies progressively. Completed-operation dialogs close where appropriate while errors or unfinished editing remain visible.

The optional full-screen device rail reuses existing device controls. Scene-grid swipes only cycle displayed device/group tabs; swiping alone does not activate a group or start playback. These display features do not add their own device polling service. The experimental headphone automatic-volume feature is not included as an active feature.
