Independent Android controller for WiiM devices

Flex4WiiM

An independent Android controller for WiiM devices.

Flex4WiiM brings device selection, saved groups, playback controls and scenes together in one interface. It is designed to complement WiiM Home and make everyday listening setups easier to manage.

Main features

One-tap device and group switching

Select an individual device or switch to a saved group configuration with a single tap.

App-managed stereo pairs

Create a stereo pair with left/right channel assignments and linked volume. These pairs can also be included in larger groups.

Up to 500 scenes

Save scene buttons that recall a device or group configuration and optionally start a preset, music folder or network stream.

Full-screen control

Handle many everyday tasks without leaving the full-screen player, including device selection, playback, volume, scenes and supported input, output and EQ controls.

Scene alarms

Schedule saved scenes to run at a specified time.

One-tap sleep timer

Start a sleep timer with a single tap.

Audio analyzer (beta)

An optional analyzer display for visualizing audio.

Music sources

Access device presets, local music, shared music and network streams.

Customizable interface

Arrange sections, customize device icons and choose from 12 interface languages.

Optional home-theater features include automatic monitoring and separate follower volume and channel settings for manual group switching. These features are currently in beta.

The app also includes many other features, described in the user guide.

Requirements

  • Android 9 or later.
  • WiiM devices reachable on the same local network.

Available controls depend on the device model, firmware and playback source. App-managed stereo pairs are a Flex4WiiM feature, distinct from WiiM Home’s native stereo-pair setup.
